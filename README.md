# European Airports ATFM Delay Analysis (2019–2026)

An analysis of Air Traffic Flow Management (ATFM) and Air Traffic Control (ATC) delays across Europe's busiest airports. This project investigates the root causes of flight delays and visualizes historical traffic trends.

**Core Objectives**
* Calculate the share of departure delays caused specifically by local ATC.
* Identify which airports are hit hardest by arrival ATFM delays based on season, weekday, and traffic level.
* Analyze whether ATFM slot adherence deteriorates during high-delay periods.
* Forecast an airport's daily arrival ATFM delay one week ahead.

**Data Source**
The data used in this project is provided by the [EUROCONTROL Aviation Intelligence Portal](https://ansperformance.eu/data/). It is used strictly for non-commercial, educational purposes in compliance with Eurocontrol's copyright notice.

**Tools Used**
* Python (Pandas, Matplotlib)
* Jupyter Notebook

**How to Run**
1. Clone or download this repository to your local machine or Google Colab.
2. Ensure the `data_atfm` folder and the `.ipynb` notebook are located in the same directory.
